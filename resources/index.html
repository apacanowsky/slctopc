Official Trail Resources

This connection would plug into a larger effort already underway. The state maintains its own interactive map and master plan for a growing, connected statewide trail network — useful context for anyone digging into where this piece fits.

  • Utah Trail Network Map

    UDOT's interactive map of existing and planned trails statewide. Zoom to the Parleys Canyon corridor to find R2-046 — Parley's Trail Gap, the exact segment this campaign is about.

  • Utah Trail Network Master Plan

    The state's official planning document behind the $95 million investment in statewide trails — background on how "Gap Closure" and "Vision Corridor" projects get prioritized and funded.

More resources will be added here as this project turns up other useful studies, plans, and data. Know of something that should be listed? Let us know.
